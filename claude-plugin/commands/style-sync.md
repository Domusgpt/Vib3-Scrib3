# Vib3 Scribe Style Sync

Ask the user for:
- Audience and tone goal (e.g., "enterprise customer success", "founder update").
- Three representative paragraphs of their writing.
- Any phrases or sign-offs to reuse.

Return:
1. A name for the profile.
2. A 2–3 sentence style abstract.
3. Bullet rules covering voice, cadence, formatting, and forbidden patterns.
4. A ready-to-use onboarding checklist for the team.

Conclude by suggesting the user store the profile in `/profiles` and sync it to the workspace settings.
